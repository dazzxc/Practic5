# Data Quality Tool (Web-версия)

Веб-сервис для аудита качества данных.  
Позволяет загружать файлы **CSV**, **Excel** и **JSON** любого размера и получать подробный отчёт о найденных ошибках (пропуски, дубликаты, нарушения форматов и т.д.).

---

## Архитектура проекта

Проект состоит из трёх основных частей:

| Часть | Папка | Технологии | Назначение |
|-------|-------|------------|----------|
| **Frontend** | `/Practic` | React + Vite | Интерфейс загрузки файлов, KPI-карточки, таблица ошибок, история отчётов |
| **Backend** | `/backend-python` | FastAPI + Uvicorn | Приём файлов, запуск QA-проверок, экспорт отчётов |
| **QA Engine** | `/qa_checks` | Pandas + NumPy | Независимый модуль проверок качества данных |

---

## Ключевые особенности

- **Работа с большими файлами** — чтение по чанкам (по 15 000 строк), файлы 10+ ГБ обрабатываются без `MemoryError`
- **Умный поиск дубликатов** — хэширование строк (всего 8 байт на строку)
- **Полностью кастомные проверки** — без pandera, только pandas + numpy
- **Экспорт отчётов** — в JSON и красивый Excel (2 листа: сводка + ошибки)
- **Визуализация** — Donut-графики и KPI-карточки
- **История отчётов** — можно открывать предыдущие проверки
- **Удобный интерфейс** с закреплённой навигацией

## Быстрый запуск (рекомендуется)

В корне проекта лежит файл **`start.bat`**.

Просто дважды кликни по нему. Он автоматически:

1. Запустит Backend на `http://127.0.0.1:8000`
2. Запустит Frontend на `http://localhost:5173`
3. Откроет сайт в браузере

После запуска появятся два окна терминала. Их можно свернуть.  
Чтобы остановить серверы — закрой оба окна или нажми `Ctrl+C` в них.

> **Перед первым запуском** создай виртуальное окружение:
> ```bash
> python -m venv backend-python\venv
> ```

## Ручной запуск

### 1. Backend (FastAPI)

```bash
# Переходим в папку бэкенда
cd backend-python

# Создаём виртуальное окружение (только первый раз)
python -m venv venv

# Активируем окружение
venv\Scripts\activate          # Windows
# source venv/bin/activate     # Linux / macOS

# Устанавливаем зависимости
pip install -r ../requirements.txt

# Запускаем сервер
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```
### 2.Frontend(React + Vite)
```bash
# Переходим в папку фронтенда
cd Practic

# Устанавливаем зависимости (только первый раз)
npm install

# Запускаем dev-сервер
npm run dev -- --host
```
