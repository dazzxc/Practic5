# Data Quality Tool (Web-версия)

Веб-сервис для аудита качества данных. Позволяет загружать файлы (CSV, Excel, JSON) любого размера и получать детальный отчет о найденных ошибках (пропуски, дубликаты, нарушения форматов и т.д.).

## 🏗 Архитектура проекта

Проект разделен на три основных слоя:
1. **Frontend (`/Practic`)**: React (Vite). Отвечает за интерфейс загрузки файлов (Drag-and-Drop), отображение KPI-карточек и таблицы с ошибками.
2. **Backend (`/backend-python`)**: FastAPI. Принимает файлы, управляет временным хранилищем, запускает QA-движок и отдает результат в формате JSON. Также реализует экспорт отчетов в Excel и JSON.
3. **QA Engine (`/qa_checks`)**: Pandas. Независимый модуль проверок, написанный на чистом Python. 

## ⚡ Ключевые особенности
* **Работа с большими файлами (Chunking):** Движок проверок не загружает файл в оперативную память целиком. Он читает его кусками (по 15 000 строк), что позволяет обрабатывать файлы размером 10+ ГБ без ошибок `MemoryError`.
* **Отказ от pandera:** Все проверки написаны на кастомном коде с использованием `pandas` и `numpy` для максимальной стабильности.
* **Умный поиск дубликатов:** Для поиска дублей между чанками используется хэширование строк (8 байт на строку), что экономит память.
* **Экспорт отчетов:** Результаты можно выгрузить в формате JSON или в красивом Excel-файле (2 листа: сводка и ошибки).
* Визуализация данных: интерактивные графики (Donut chart) и KPI-карточки.
* История отчетов с возможностью открытия и просмотра деталей.
* Удобный интерфейс с закрепленной навигационной панелью

## 🚀 Инструкция по локальному запуску

Для работы потребуется установленный **Python 3.10+** и **Node.js 18+**.

### Запуск Backend (FastAPI)
🐍 Терминал 1: Бэкенд (Python)
Убедись, что ты в корневой папке проекта (Practic5). Если нет, выполни:

powershell
cd C:\Users\user\Documents\GitHub\Practic5
Запусти сервер напрямую через Python из виртуального окружения. Эта команда работает всегда, потому что она не требует активации окружения (скрипты активации заблокированы).

powershell
cd backend-python
..\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
Дождись строки Application startup complete. Не закрывай этот терминал и не вводи в него больше ничего.

⚛️ Терминал 2: Фронтенд (React)
Открой новый терминал (нажми +).

Перейди в папку с фронтендом:

powershell
cd C:\Users\user\Documents\GitHub\Practic5\Practic
Если ты давно не устанавливал зависимости (или скачал проект заново), выполни:

powershell
npm install
(Если npm ругается на политику безопасности, используй npm.cmd install)

Запусти сервер разработки:

powershell
npm run dev
(Если и здесь ошибка, используй npm.cmd run dev)
