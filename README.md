# Data Quality Tool

Сайт для проверки качества данных. Загружаешь CSV, Excel или JSON - получаешь отчёт:
пропуски, дубликаты, некорректные значения и несогласованности между колонками.

## Из чего состоит

| Часть | Папка | На чём | Что делает |
|-------|-------|--------|------------|
| Фронтенд | `ReactHost/` | React + Vite | Загрузка файла, карточки, диаграмма, таблица ошибок, история отчётов |
| Бэкенд | `backend-python/` | FastAPI | Принимает файл, запускает проверки, отдаёт отчёт и выгрузку в Excel/JSON |
| Проверки | `qa_checks/CHECKS/` | pandas + numpy | Сами проверки, можно запускать и без сайта |

## Что умеет

- Читает файлы кусками по 15 000 строк, так что большие файлы не забивают память.
- Сам подбирает правила под колонки файла: email, числа, даты, id, пары дат начало/конец и т.д.
- Дубли ищет по хешам строк - 8 байт на строку, поэтому находит копии даже в разных кусках файла.
- Отчёт можно скачать в JSON и Excel (лист со сводкой + лист с ошибками).
- Во вкладке «Отчёты» хранится история проверок, любой отчёт можно открыть заново.

## Что нужно

- Python 3.10+ (мы пользуемся 3.12)
- Node.js 18+ и npm

## Первый запуск

Всё из корня проекта (`Practic5`):

```
python -m venv backend-python\venv
backend-python\venv\Scripts\python -m pip install -r requirements.txt
cd ReactHost
npm install
```

Потом просто запускай `start.bat` двойным кликом. Он откроет два окна (бэкенд и фронтенд)
и сайт в браузере. Чтобы остановить - закрой оба окна.

## Запуск руками

Бэкенд:
```
cd backend-python
venv\Scripts\activate
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Фронтенд (во втором терминале):
```
cd ReactHost
npm run dev
```

- Сайт: http://localhost:5173
- Бэкенд: http://127.0.0.1:8000
- Документация API: http://127.0.0.1:8000/docs

## Тестовые файлы

Лежат в `qa_checks/CHECKS/test_data/`. Для показа удобнее всего `demo_*` - в них есть
ошибки всех видов, а `demo_clean.csv` чистый. Подробнее в `qa_checks/CHECKS/README.md`.

## Структура

```
Practic5/
├── ReactHost/            # фронтенд
├── backend-python/       # бэкенд
│   ├── app/
│   └── uploads/          # загруженные файлы, удаляются через 3 дня
├── qa_checks/CHECKS/     # проверки
├── loaders/              # загрузчики CSV/JSON (отдельный модуль)
├── backend/app/db_connector/  # подключение к БД (в работе)
├── prototype/            # первая версия на PyQt
├── tests/                # тесты загрузчиков
├── start.bat             # запуск всего одной кнопкой
└── requirements.txt      # библиотеки Python
```

## Важно знать

История отчётов хранится в памяти сервера: после перезапуска бэкенда она пропадает.
