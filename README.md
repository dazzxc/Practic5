========================================================================
ДОКУМЕНТАЦИЯ К ГЕНЕРАТОРУ ТЕСТОВЫХ ДАННЫХ (DATA GENERATOR GUIDELINES)
========================================================================

Файл `test-files-generator.py` предназначен для автоматического создания 
больших синтетических датасетов, которые симулируют реальные производственные 
выгрузки с умышленно заложенными ошибками качества данных.

------------------------------------------------------------------------
1. ИНСТРУКЦИЯ ПО РАЗВЕРТЫВАНИЮ И ЗАПУСКУ С КОРРЕКТНЫМИ БИБЛИОТЕКАМИ
------------------------------------------------------------------------
Ввиду того, что политики безопасности Windows (Execution Policies) могут 
блокировать скрипты активации локальных виртуальных окружений (.venv) в PowerShell,
самым надежным способом развертывания является глобальная установка зависимостей.

Выполните в терминале из КОРНЯ проекта (папка Practic5) по очереди:

ШАГ 1: Установка необходимых библиотек для работы с данными и Excel:
   python -m pip install pandas numpy openpyxl

ШАГ 2: Запуск генерации файлов:
   python test-files-generator.py

После завершения работы в директории будут созданы два тяжелых файла:
- `large_users_quality.csv` (~10 000 строк)
- `large_transactions_quality.csv` (~50 500 строк)

------------------------------------------------------------------------
2. ОСОБЕННОСТИ ФОРМИРОВАНИЯ И СОВМЕСТИМОСТИ С EXCEL / WPS OFFICE
------------------------------------------------------------------------
Чтобы генерируемые CSV-файлы корректно распознавались табличными редакторами 
(Excel, WPS Office, LibreOffice) на русскоязычных операционных системах, 
в коде генератора жестко зафиксированы следующие параметры экспорта:

1. Разделитель полей: Точка с запятой (sep=";") — предотвращает слипание 
   всех колонок в одну текстовую строку "А".
2. Кодировка файлов: UTF-8 с BOM-сигнатурой (encoding="utf-8-sig") — 
   гарантирует корректное отображение кириллицы (ФИО пользователей) 
   без иероглифов и "кракозябр".

------------------------------------------------------------------------
3. ТЕХНИЧЕСКИЕ АНОМАЛИИ В КОЛОНКЕ AMOUNT (ОБЪЯСНЕНИЕ ДЛЯ РАЗРАБОТЧИКОВ)
------------------------------------------------------------------------
При открытии файла `large_transactions_quality.csv` в колонке `amount` 
(суммы транзакций) вы обнаружите вещественные числа с длинным "хвостом" 
знаков после запятой (например: 65748.5031...).

Это НЕ является ошибкой кода. Данная аномалия заложена УМЫШЛЕННО:
1. Симуляция сырых банковских логов: В реальных финансовых системах при 
   мультивалютной конвертации, расчете кэшбэка или дробных долей транзакций 
   данные хранятся с максимальной точностью типов float/double.
2. Стресс-тестирование Quality Engine: Избыточная точность позволяет проверить, 
   насколько корректно наш аналитический движок и библиотека Pandas работают 
   с типами данных высокой точности и не происходит ли случайной потери 
   микроданных при расчете общего индекса качества (Quality Score).
