# Data Quality Tool (Web)

Инструмент для аудита качества данных, работающий с файлами любого размера (CSV, Excel, JSON).

## 🏗 Архитектура
* **Frontend:** React 19 + Vite (Загрузка файлов, визуализация KPI и найденных ошибок).
* **Backend:** FastAPI (REST API, маршрутизация, валидация через Pydantic).
* **Core Engine (QA):** Pandas (Чтение файлов чанками, проверки на пропуски, дубликаты, форматы и бизнес-логику).

## ⚡ Особенности
* **Chunking (Обработка больших данных):** Движок не загружает файл в память целиком. Он читает его кусками (по умолчанию 15 000 строк), что позволяет обрабатывать файлы размером 10+ ГБ без ошибок `MemoryError`.
* **Отказ от pandera:** Все проверки написаны на чистом `pandas` для максимальной стабильности и скорости.
* **Умный поиск дубликатов:** Дубликаты ищутся между чанками с помощью хэширования строк (храним 8 байт на строку).
